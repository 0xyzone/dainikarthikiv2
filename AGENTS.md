# Workspace Agent Rules

## Git Workflow
- Always commit changes and perform a `git push origin main` every time a task is completed.

## Design & Frontend Skills
When developing or upgrading the homepage, landing pages, and web app interfaces:
- Apply **UI UX PRO MAX** for accessibility, clean typography scales, and responsive touch ergonomics.
- Apply **Genjutsu** (`cast`, `paint`, `bunshin`) for premium, immersive visual identity and micro-interactions.
- Apply **Motion Design** for purposeful, fluid physics-based transitions.
- Apply **Three.js** for interactive 3D visual centerpieces with WebGL safeguards and smooth 60fps rendering.
- Apply **GSAP** for responsive timelines, deck/card gesture animations, and smooth bottom SPA tab transitions.
- Apply **Design DNA** for consistent tokens: Emerald `#10b981`, Teal `#14b8a6`, Deep Slate `#090d16`, with glassmorphic depth.
- Ensure mobile-first native application ergonomics: bottom SPA navigation, tactile card & deck stacks, and active PWA installation prompts.
